# Screenshots

Eight captures, all produced by this project: three head-less renders from the same
geometry kernel the web UI uses, and five captures of the running browser session.

## Head-less renders (`src/the_curved_world/render.py`)

- `01_local_tangent_view.png` - player view (local tangent map) rendered head-lessly.
- `02_omniscient_3d_view.png` - omniscient view with the hidden exit visible.
- `03_map_gallery.png` - the registered map gallery.

## Live browser session (`python -m src.main --serve --port 8000`)

- `04_lobby_enter_world.png` - the "Enter the World" lobby: map picker, geometric scale,
  the three difficulty tiers (Easy / Medium / Hard) and the seeded random seed field.
- `05_player_view_roaming.png` - player view while roaming: the seamless 2D local tangent
  map with the hill-shaded relief, the instrument panel on the right and the tool hotbar
  plus keybind strip along the bottom.
- `06_player_view_tools.png` - player view with a surveyor tool in use (the instrument
  panel shows the tool readouts and the mission hint area is active).
- `07_player_view_survey.png` - player view during a measurement pass (markers, ropes and
  measurement overlays drawn on the map).
- `08_god_view_omniscient.png` - the omniscient (God) view: the global surface mesh of the
  manifold, available from the lobby's omniscient mode or with `G` in a `--debug` session.

## Capture notes

- 01-03 come from the Matplotlib renderer, which is driven by the same simulation code as
  the browser client, so they are honest captures of the geometry rather than artwork.
- 04-08 are screenshots of the live web session at the resolution the capture produced.
  They were archived verbatim (byte-identical copies checked by SHA256); this project did not
  re-encode, crop or otherwise edit them.
- The project never ships third-party imagery: everything here is generated by the
  geometry kernel or captured from the project itself.
