# Screenshots

These images are rendered head-lessly from the *same* simulation code the
web UI uses, so they are honest captures of the geometry:

- `01_local_tangent_view.png` - player view (local tangent map) from the
  Matplotlib renderer.
- `02_omniscient_3d_view.png` - omniscient view with the hidden exit.
- `03_map_gallery.png` - the four registered maps.

The browser lobby / web canvases must be captured by hand (they need a
real browser): run `--serve`, open http://127.0.0.1:8000/ and screenshot
  04_lobby.png (the lobby modal) and 05_web_session.png (the in-game view).
Suggested names are reserved above so the numbering stays tidy.
