一、任务目标
--------------------------------------------------------------------------------
1) 把现有零散曲面与流形统一封装为“地图注册表 / 工厂”插件模式；
   外部扩展新地图只需写一个类 + 装饰器，无需改动世界生成器或服务端主逻辑。
2) 提供 Web 启动大厅：地图选择（含数学简介）、游玩模式（玩家探索 / 全知观测）、
   随机种子配置；进入后平滑过渡，游戏内可随时唤回大厅换图。
3) 补充测试并把全量 pytest 保持全绿。

二、完成的主要工作
--------------------------------------------------------------------------------
1) 地图注册表（src/the_curved_world/maps.py，新增）
   - MapMetadata：id / name / description / topology / factory / placement，
     并提供 JSON 安全的 to_dict()（工厂函数不外泄）。
   - MapRegistry（单例）：register / get / unregister / ids / list_maps / create；
     未注册 id 抛 MapNotFound（清晰列出可用 id）。
   - @register_map 装饰器：装饰类（需实现 build(self, params)）或直接装饰工厂函数；
     注册时校验 id 非空、topology 合法、factory 可调用。
   - 内置 4 张地图（自动注册）：
       torus_genus1      变形环面（亏格 1）      closed_periodic
       ellipsoid_genus0  波动椭球（亏格 0）      closed_periodic
       double_torus      双孔近似（亏格 2 外观）  closed_periodic
       planar_landscape  经典平面图曲面          bounded_plane
   - world_config_for(map_id)：按地图元数据的 placement 生成 WorldConfig；
   - map_id_for(config)：反向查询地图 id（未注册返回 "custom"）。

2) 服务端适配（src/the_curved_world/server.py）
   - GameSession 新增 map_id / mode / startup_debug；
     mode = "player" | "god"（--debug 启动时默认 god）。
   - 新增 reset_world(map_id, seed, mode)：按地图重建世界、探测器与玩家位置；
     新增 summary() 返回 {map_id, mode, seed, periodic}。
   - 新增 GET /api/maps：返回全部地图元数据 + 默认 id。
   - 新增 POST /api/session/new：{map_id, seed, mode} -> 会话重置。
   - 安全门禁：mode == "player" 时 /api/state/debug **一律** 403，
     无论客户端发什么请求；只有全知模式或以 --debug 启动才放行。
   - 玩家状态新增 map_id / mode / periodic（均非特权信息）。

3) 入口与命令行切图（src/main.py、demo.py）
   - 新增 --map {torus_genus1, ellipsoid_genus0, double_torus, planar_landscape}。
   - --play / --serve / --demo / --demo-scenario 全部支持 --map；
     serve() 支持 map_id / world_config 参数。
   - Demo 起始行会打印所用地图名。

4) Web 启动大厅（web/index.html、web/style.css、web/app.js）
   - 毛玻璃大厅 #lobby-modal：默认开启，居中弹出，带淡出过渡。
   - 地图下拉框由 GET /api/maps 动态填充，切换时显示该地图的数学简介。
   - 游玩模式单选：玩家探索 / 全知上帝视角；种子输入框（留空随机）。
   - 「进入学院」-> POST /api/session/new -> 清空本地迷雾/选择/指向器 -> 刷新并淡出大厅；
     全知模式自动展开三维全局网格并高亮出口。
   - 顶部「🔄 新世界 / 选图」按钮可随时唤回大厅。
   - 非法种子/非法地图的错误在面板内提示，不会崩溃。

5) 验证
   - 全量 pytest 130 项全绿（原有 119 项无破坏性改动）。
   - 端到端实测：GET /api/maps 返回 4 张地图；依次切到
     torus/player、ellipsoid/god、double_torus/player 均成功；
     玩家模式下 /api/state/debug 返回 HTTP 403；非法 map_id 返回 HTTP 400 且报错清晰。

六、如何启动与自测
--------------------------------------------------------------------------------

    .\.venv\Scripts\python.exe -m src.main --serve --port 8000

  直接以某张地图启动（跳过选择）
    .\.venv\Scripts\python.exe -m src.main --serve --map torus_genus1
    .\.venv\Scripts\python.exe -m src.main --serve --map ellipsoid_genus0 --debug
    .\.venv\Scripts\python.exe -m src.main --serve --map double_torus
    .\.venv\Scripts\python.exe -m src.main --serve --map planar_landscape

  终端实时游玩 / 可复现 Demo
    .\.venv\Scripts\python.exe -m src.main --play --map torus_genus1 --seed 12345
    .\.venv\Scripts\python.exe -m src.main --demo-scenario --map planar_landscape

  接口自测（curl 示例）
    curl http://127.0.0.1:8000/api/maps
    curl -X POST -H "Content-Type: application/json" -d "{\"map_id\":\"ellipsoid_genus0\",\"seed\":7,\"mode\":\"god\"}" http://127.0.0.1:8000/api/session/new
    curl http://127.0.0.1:8000/api/state/player
    curl -i http://127.0.0.1:8000/api/state/debug        （玩家模式应返回 403）

  本轮实测样本
    GET /api/maps -> 4 张地图，default = torus_genus1
    POST /api/session/new {torus_genus1, 12345, player} -> 会话就绪（periodic=True）
    POST /api/session/new {ellipsoid_genus0, 7, god}    -> debug 模型 deformed ellipsoid
    切回 player 模式 -> /api/state/debug 返回 HTTP 403
    非法 map_id -> HTTP 400，错误信息列出可用 id

七、已知限制（如实标注）
--------------------------------------------------------------------------------
1. 地图元数据中的 factory 不可 JSON 序列化，to_dict() 已按设计剔除。
2. 大厅的“全知模式”会直接放行 /api/state/debug（这是设计意图：答辩演示用）；
   若要强制限制，可只用 --debug 启动并以玩家模式游玩。
3. 地图热插拔仅限同进程内注册；新增地图文件需要被导入才会执行装饰器。
4. 前端大厅状态（地图/模式/种子）保存在内存，刷新页面会回到默认。
5. 之前各任务的已知限制（椭球两极拓扑退化、数值曲率积分、迷雾本地维护、
   指向器为限次量化提示等）依然成立。
