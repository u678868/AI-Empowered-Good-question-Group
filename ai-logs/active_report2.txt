一、任务目标
--------------------------------------------------------------------------------
把渲染从 Matplotlib 解耦，交给轻量 Web 前端；Python 只保留“数学内核 + 安全 API”。
- 轻量易配置：原生 HTML5 + ES6 模块 + 极简 CSS，无打包编译、无 CDN（可完全离线）。
- Python 端只用标准库 http.server 提供本地 HTTP 接口，不新增依赖。
- Python 负责：确定性世界生成、流形曲面高阶偏导、高斯曲率解析、探测器信号衰减、
  信息泄露边界控制。
- 前端负责：键盘/鼠标交互、本地迷雾系统、“玩家局部视角”与“上帝视角”渲染。

二、完成的主要工作
--------------------------------------------------------------------------------
1) API 服务层（src/the_curved_world/server.py，新增；仅标准库）
   - GameSession：持有一个游戏实例，把动作/状态转成 JSON 载荷（与 HTTP 解耦，可单测）。
   - CurvedWorldHandler：路由 + 静态文件服务（含路径穿越防护）。
   - 接口：
       POST /api/action/move   方向输入 -> 参数坐标 / 3D 坐标 / 信号 / 夹紧标记 / 步数
       POST /api/action/tool   scan / mark / measure / curvature / angle_sum
       GET  /api/state/player  坐标 / 局部曲面块 / 轨迹 / 标记 / 信号与趋势 / 曲率
       GET  /api/state/debug   特权：全局网格采样 + 出口真实三维坐标（仅 --debug）
   - 默认只绑定 127.0.0.1；响应带 Cache-Control: no-store。

2) Web 静态前端（web/，新增；无构建流程）
   - index.html / style.css / app.js（原生 ES6 模块）。
   - Player View（主视窗）：玩家平面局部视角 + 探索迷雾（Fog of War，浏览器本地维护）
     + 分层等高着色 + 网格；叠加轨迹、标记与玩家位置。
   - Instrument Panel：探测器表盘（弱/中/强指针与配色）、局部高斯曲率数值、
     命名标记管理（点选参与测量）、测地三角内角和工具。
   - God View：按 G 展开/收起的全局透视曲面视窗（需 --debug），支持鼠标拖拽旋转。
   - 交互：WASD / 方向键移动，G 切换上帝视角，C 读取曲率。

3) 几何内核扩展
   - SmoothSurface.tangent_angle()：在切平面内测量两个方向的夹角（明确标注为切平面近似）。
   - ExplorationGame.triangle_angle_sum()：三角形三顶点的切平面内角和与超出 pi 的余量。

4) 入口适配（src/main.py）
   - 新增 --serve / --host / --port / --debug。

5) 安全与依赖边界（CRITICAL）
   - 玩家端接口不含出口坐标、真实距离或任何特权字段（测试含正向对照）。
   - /api/state/debug 仅在 --debug 下存在，否则返回 403。
   - 前端与接口中不含任何影响 AI 评审的语句（有自动化扫描测试）。
   - requirements.txt 未新增依赖（Web 层仅使用标准库）。

六、如何启动 Web 双视角模式
--------------------------------------------------------------------------------

    .\.venv\Scripts\python.exe -m src.main --serve --port 8000

  额外开启特权调试接口（/api/state/debug）
    .\.venv\Scripts\python.exe -m src.main --serve --debug

  浏览器打开：http://127.0.0.1:8000/

  接口自测（curl 示例）
    curl http://127.0.0.1:8000/api/state/player
    curl -X POST -H "Content-Type: application/json" -d "{\"dx\":1,\"dy\":0}" http://127.0.0.1:8000/api/action/move

七、已知限制（如实标注）
--------------------------------------------------------------------------------
1. 前端为原生 Canvas 2D 实现：Player View 是“局部平面”表达，God View 使用简单透视
   投影（画家算法排序四边形），不是 GPU 实时光照/着色。
2. 迷雾系统在浏览器本地维护，刷新页面会重置；不写入后端。
3. 三角内角和是“切平面角度”的近似，不是严格测地三角计算（代码与文档均已标注）。
4. 无 WebSocket：交互为 HTTP 请求/响应式刷新，未做长连接推送。
5. 仅监听 127.0.0.1，未做多用户/并发会话隔离（面向单会话演示）。
