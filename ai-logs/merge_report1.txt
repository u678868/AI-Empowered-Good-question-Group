二、网络问题与处理
--------------------------------------------------------------------------------
- 现象：git fetch 报 "schannel: failed to receive handshake, SSL/TLS connection failed"；
  TCP 443 可连（Test-NetConnection=True），换 OpenSSL 后端报
  "unexpected eof while reading"，系统自带 curl 同样失败 —— 典型 TLS 握手被切断。
- 定位：用户本机代理监听 127.0.0.1:7890，但 git 未配置代理（http.sslBackend=schannel，
  无 proxy 配置）。配好代理后一次通过。
- 处理：仅在**本仓库**设置 `git config --local http.proxy http://127.0.0.1:7890`，
  未改全局配置；撤销命令：`git config --local --unset http.proxy`。
- 推送鉴权由系统 Git Credential Manager 提供，无需交互。

四、合并后的三处修复
--------------------------------------------------------------------------------
1) config.py 缩进错误（合并产物）
   DISTANCE_MODES 等模块级常量落在类体中间 -> 全部 27 个测试模块收集失败
   （IndentationError: unexpected indent）。已把常量移到类定义之后。

2) hideCard is not defined（用户报告："无论选什么都会提示"）
   根因：上游 release 删除了工具栏/结果卡 UI（连同 hideCard 函数），而冲突解决时保留了
         本分支在 enterWorld() 里的 hideCard() 调用 -> 每次从大厅进入世界都抛异常。
   修复：删除该调用，保留同处的 state.debugState = null（上帝视角修复）。
   验证方式升级（原先只跑 node --check，查不出未定义调用）：
     - node 侧静态扫描：提取全部被调用标识符与定义比对，现仅剩字符串字面量误报；
     - 无头 Edge 跑真实流程：进入世界 / 快捷槽 1-5 / 上帝视角 / Esc / 重开大厅换图重进，
       三种配置 + 重进流程，TOTAL ERRORS = 0。

3) sync_position 的 2π 硬折回（上游新增代码的语义接缝）
   上游用 wrap_parameter(du) 按 2π 折回增量；克莱因瓶 u 周期是 4π、射影平面有 4 层 chart
   -> 语义错误。改为向 chart 要最近代表 chart_relative()，保留原兜底分支。
