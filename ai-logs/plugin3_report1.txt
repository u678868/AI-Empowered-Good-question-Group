二、Task 16 功能改动
--------------------------------------------------------------------------------
1) 障碍物尺度（src/the_curved_world/config.py、maps/builtin.py）

   | 配置 | 障碍数量 | 半径 原 -> 新 | 安全边距 原 -> 新 |
   | :--- | :--- | :--- | :--- |
   | WorldConfig 默认值 | 12 | 1.2 -> 3.5 | 6.0 -> 12.0 |
   | torus_genus1 | 30 | 4.0 -> 4.2 | 32 -> 45 |
   | ellipsoid_genus0 | 12 -> 8 | 1.3 -> 2.4 | 7 -> 12 |
   | double_torus | 16 | 1.3 -> 4.5 | 7 -> 12 |
   | planar_landscape | 18 | 1.8 -> 4.5 | 8 -> 16 |

   说明：环面地图半径受"障碍物互不重叠（间距 2.5 * 基础半径）+ 30 个障碍物"与
   测试所用小环面 default_manifold 的容量共同约束，因此环面采用 4.2 并同时提高
   前端最小像素半径来保证视觉存在感；其余三张地图半径提升约 1.8x ~ 3.5x。
   已用 seeds 0..3 验证四张地图均能生成满额障碍物，且每个障碍物到出生点/出口的
   环境三维距离 >= obstacle_safe_margin。

2) 前端"所见即所撞"（web/app.js）

   - MIN_OBSTACLE_PX 7 -> 12、MIN_PLAYER_PX 2.5 -> 4；
   - 障碍物半径按其**所在位置**的局部度量（双线性插值的 E/G）换算为参数半径，
     绘制半径与硬碰撞圆盘使用同一个 obstacleParam，不再出现"画得比撞得大/小"；
   - 玩家圆点外新增碰撞体半径环，接触障碍物时可直接看到"身体贴边"。

3) 通关结算弹窗与流转（web/index.html、web/style.css、web/app.js）

   - 新增 #victory-modal：毛玻璃卡片 + 轻量庆祝微光动画（victory-pulse）；
   - 摘要字段：#victory-steps（步数）、#victory-readings（探测器读数次数）、
     #victory-markers（标记数）、#victory-time（本次进入世界后的耗时 mm:ss）、
     #victory-map（地图名）、#victory-topology（拓扑）、#victory-seed（种子）；
   - 触发：服务端 /api/state/player 或 sync_position 返回 won: true 时，
     applySnapshot() -> maybeShowVictory() 只弹出一次；
   - Continue Free Roam：关闭弹窗、顶部 #cleared 徽章显示 "Cleared"，
     玩家可继续在当前曲面测量/自由漫游；
   - Return to Lobby：关闭弹窗并重新呼出 #lobby-modal 启动大厅；
   - 新增 UI 文案全部为英文，避免编码乱码与中文字符测试报警。

4) 新增测试与打包工具

   - tests/test_obstacle_scale.py：固定 Task 16 的四图障碍物半径与安全边距，
     并验证多随机种子下仍能满额生成且出生点/出口安全距离成立；
   - scripts/package_submission.py：新增 --output（默认仍为 submission/），
     可把 src/、web/、tests/、docs/、README.md、AI_USAGE.md、ai-logs/、
     screenshots/、DEMO_LINK.md 等打包到指定暂存目录；DEMO_LINK.md 文案刷新为
     当前 2D 俯视玩法 + Task 16 演示脚本。

   结果：exit code 0；进度输出 72 + 72 + 15 = 159 个点全部通过

2. 前端语法：

3. 中文扫描（Web UI 必须全英文）：
   命令：Select-String -LiteralPath 'web\index.html','web\app.js','web\style.css'
         -Pattern '[\u4e00-\u9fff]'
   结果：无匹配

4. 浏览器自测（本地服务：
   .\.venv\Scripts\python.exe -m src.main --serve --port 8123 --debug）：
   a) 服务端把玩家 sync_position 到 torus_genus1 / seed 12345 的出口
      (u=1.8684, v=1.1074) 后，/api/state/player 返回 won=true；
   b) 前端加载后 #victory-modal 可见，摘要实际值：
      steps=0、readings=0、markers=0、time=00:00、
      map=Deformed Torus (genus 1)、topology=closed periodic manifold、seed=12345；
   c) 点击 Continue Free Roam：#victory-modal 变为 hidden、#cleared=badge ok；
   d) 重新注入胜利后点击 Return to Lobby：#victory-modal 变为 hidden、
      #lobby-modal 恢复为 modal；
   e) 两次浏览器测试 dev.logs 均为空（无 JS 报错）。
   说明：为了无需真实走完整个流形即可验证弹窗，自测时通过服务端 sync_position
   直接注入出口参数；正式游玩仍由真实移动触发 won。

5. 障碍物视觉自测：
   同一 torus_genus1 视野内，障碍物绘制半径由原先的
   max(r/unit*scale, 7/300*viewRadius*scale) 提升为
   max(r/unit*scale, 12/300*viewRadius*scale)；
   平面地图半径 1.8 -> 4.5，俯视树冠/岩石明显变大（约 2.5x 半径）。
