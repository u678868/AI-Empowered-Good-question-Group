一、任务目标
--------------------------------------------------------------------------------
把“有界平面高度图曲面”重构为“紧致正则的三维封闭流形系统”：
1) 三套可调参的正则封闭曲面模型（亏格 1 环面 / 亏格 0 椭球 / 双孔近似）；
2) 解析一阶、二阶偏导，第一/第二基本形式与高斯曲率 K；
3) 取消边界钳制，改为周期坐标环绕，支持无界行走；
4) 探测器仍用环境三维欧氏距离，体现“隔面近在咫尺、行走需绕大圈”；
5) Web 前端同步：周期迷雾、环绕足迹、封闭三维上帝视角；
6) 原有 API 测试与信息边界测试在新曲面下 100% 通过。

二、完成的主要工作
--------------------------------------------------------------------------------
1) 封闭流形引擎（src/the_curved_world/manifold.py，新增）
   - 抽象基类 ClosedManifold：统一参数域 (u, v) in [-pi, pi) x [-pi, pi)。
     基类派生法向 n、第一基本形式 E/F/G、第二基本形式 L/M/N、
     K = (L N - M^2)/(E G - F^2)、面积元 sqrt(E G - F^2)、切线夹角、
     采样网格、数值面积与曲率积分。全部解析，不使用运行时数值差分。
   - 模型 A：DeformedTorus（默认，亏格 1）
       r(u,v) = ((R + rho cos u) cos v, (R + rho cos u) sin v, rho sin u)
       rho(u,v) = r0 + sum A_k cos(k u + phi_k) + sum B_l sin(l v + psi_l)
       构造时校验 R > max|rho| > 0 且 E G - F^2 > 0（处处正则）。
   - 模型 B：DeformedEllipsoid（亏格 0）
       r(u,v) = (a m(v) sin v cos u, b m(v) sin v sin u, c m(v) cos v)
       仅允许径向（axis='v'）调制，以保住两极的退化结构。
   - 模型 C：GenusTwoApproximation（双孔外观近似）
       环半径调制 R(u) = R0 + R1 cos(2u) + 管半径谐波，E G - F^2 > 0 处处成立。
   - 周期环绕：wrap_parameter(x) = ((x + pi) mod 2pi) - pi。

2) 玩法与世界生成适配（world.py / gameplay.py / config.py）
   - default_config() 的默认曲面改为 DeformedTorus；
     min_separation=12、boundary_margin=0、detector_scale=12（三维环境距离）。
   - 移动改为周期环绕：周期曲面上不再钳制、也不再报告 clamped；
     平面图曲面（保留）仍走原有钳制路径。
   - 出口为流形上的随机参数点；探测器保持环境三维欧氏距离。
   - 标记存于周期参数空间；measure 仍为两点三维直线距离；
     测角仪与高斯-博内仍在局部切空间成立。

3) Web 与双视角同步（server.py / web/app.js / web/style.css）
   - /api/state/player：补丁以玩家为中心（半径 = 0.22 x 参数域跨度），
     附带 E/F/G；z 取嵌入坐标第三分量（图曲面=高度，流形=三维 z）；
     新增 periodic 标志。
   - /api/state/debug：返回**三维坐标网格** X/Y/Z 与通用模型描述，可渲染封闭三维网格。
   - 前端：迷雾升级为**环面周期位图**（索引前先 wrap，跨接缝不撕裂）；
     历史足迹与标记按 universal cover 展开（unwrapNear），跨界无跳变；
     上帝视角改为渲染封闭三维网格（四边形画家算法 + 深度排序）。

4) 验证
   - 解析 vs 数值偏导：一阶最大误差 < 1e-6；二阶（h=1e-4）最大误差 < 1e-3。
   - 正则性：环面与双孔近似 min(E G - F^2) > 0、退化占比 0；
     椭球仅在两极退化（退化占比约 2.2%，为拓扑必然）。
   - 高斯-博内（iint K dA）：环面 0.0000（理论 0）、
     椭球 24.53（双覆盖理论 8 pi = 25.13，极点退化导致约 2.4% 数值偏差）、
     双孔近似约 0.08（理论 0）。
   - 连续行走 400 步：坐标始终落在 [-pi, pi)，clamped 恒为 False。
   - 端到端：种子 12345 的可复现 Demo 在封闭环面上 18 步 / 11 次读数 / 2 个标记 获胜；
     Web 实测三角形内角和 272.3 度、iint K dA = 2.33（同为正曲率隆起），指向器正常。

七、已知限制（如实标注，含拓扑必然性）
--------------------------------------------------------------------------------
1. 用 [-pi, pi)^2 做**正则**参数化，其像必然是亏格 1。因此：
   - 环面与双孔近似模型处处正则；
   - 亏格 0 的椭球**必然**存在 2 个参数退化点（两极），K 公式使用分母下限避免除零；
   - 真正的亏格 2 需要亏格 2 的参数域，模型 C 只是“双孔外观近似”，非真亏格 2。
2. 椭球的曲率积分因极点退化有约 2.4% 数值偏差（24.53 vs 25.13）。
3. 曲率面积分与总面积为**数值**积分（周期性中点法），非解析积分。
4. 前端玩家视图是 Canvas 2D 的局部平面表达，网格畸变是视觉提示，不是等距嵌入。
5. 迷雾在浏览器本地维护，刷新页面重置。
6. 指向器是有限次、量化的方向提示，仍不返回出口坐标与精确距离。
