一、项目概述
--------------------------------------------------------------------------------
项目名称：The Curved World（弯曲世界）
项目类型：数学探索原型（Python）

玩法：玩家在一块嵌入普通三维欧氏空间的光滑曲面上移动，唯一的线索是一个
“距离敏感探测器”——越靠近隐藏出口，信号越强；但探测器不告诉玩家精确距离、
出口坐标或方向。玩家需要通过移动、比较信号、放置标记来定位出口。

实现范围：Task 1 ~ Task 4，全部完成，测试通过。

二、完成的主要工作
--------------------------------------------------------------------------------
(0) 环境配置
    - 基于本机 Python 3.13.2 创建虚拟环境 .venv
    - 安装依赖：numpy 2.5.4、matplotlib 3.11.2、pytest 9.1.1

(1) Task 1 —— 数学世界引擎
    - 光滑图曲面 S = {(x, y, f(x, y))}，f = 正弦波 + 若干高斯丘，全部 C-无穷
    - 偏导数解析求解（不使用运行时数值差分）
    - 确定性世界生成：同一 (配置, 种子) 完全复现；起点/出口在域内且满足最小间距
    - 距离敏感探测器 signal = exp(-d / scale)，严格单调、有界 (0, 1]
    - 信息边界：内部状态 / 玩家观测 / 调试接口 三者架构级分离

(2) Task 2 —— 探索玩法
    - 参数空间移动：边界钳制、对角归一化、每步重算曲面高度
    - 观测：信号 + 定性标签(Weak/Moderate/Strong) + 升降趋势(up/down/same/first)
    - 探索日志、命名标记、测量探针（只测两个标记点之间的直线距离）
    - 捕获半径胜利条件 + 完成摘要（读数数/标记数/步数/时间/种子）
    - 终端命令界面 + 完整输入校验（非数字、重名标记、未知标记、非法种子等均不崩溃）

(3) Task 3 —— 3D 可视化与开发者调试视图
    - build_scene() 把游戏状态转为纯数据场景；MatplotlibRenderer 只负责绘制
    - 渲染层与仿真层彻底分离；绘图曲面始终取自仿真的同一个 SmoothSurface
    - 采样网格带缓存：仅当曲面或分辨率变化时才重建
    - 玩家标记恒画在 (x, y, f(x, y)) 上
    - 玩家视图不泄露隐藏状态；开发者视图（显式开启）显示出口/真实距离/种子/参数

(4) Task 4 —— 验证与可复现 Demo
    - 可复现 Demo 场景 run_demo()（固定种子 12345）
    - 数学审计测试、信息泄露审计测试、端到端 Demo 测试
    - 最终验证报告 docs/final_report.md
    - 清理未用导入；确认无提交任何缓存/生成物

三、文件功能说明
--------------------------------------------------------------------------------
【源码 src/the_curved_world/】
  config.py         配置数据类与参数校验：
                    Domain / WaveComponent / GaussianHill / SurfaceConfig / WorldConfig；
                    非法值一律抛 ConfigError
  geometry.py       SmoothSurface：height / position / gradient(解析) / normal /
                    contains / sample_grid；ambient_distance（环境欧氏距离）
  detector.py       Detector（特权）：distance / signal = exp(-d/scale)；
                    DetectorConfig（scale 必须 > 0）
  observations.py   信息边界：ObservationConfig（标签阈值）、
                    PlayerObservation（signal/label/trend）、PlayerObserver、
                    PlayerView（以上玩家侧对象均结构上无法访问出口）
  world.py          WorldState（特权内部状态）、DebugView（特权调试接口）、
                    WorldGenerator（种子可复现）
  gameplay.py       ExplorationGame：移动、观测与日志、标记、测量、胜利、轨迹；
                    以及 GameplayConfig / Marker / LogEntry / MoveResult / GameSummary
  render.py         PlotMode / RenderConfig / SurfaceMeshCache / Scene /
                    build_scene() / MatplotlibRenderer（Matplotlib 3D 渲染）
  demo.py           run_demo()：可复现的完整 Demo 场景（打印真实读数）
  cli.py            GameCLI：终端命令解析、结果呈现、视图切换
  __init__.py       包导出（公共 API 与版本号）

【入口】

七、已知限制（如实标注）
--------------------------------------------------------------------------------
1. 探测器为确定性模型，暂无测量噪声。
2. 移动在参数空间进行，不是测地线运动，也不是物理真实的行走模拟。
3. Matplotlib 界面是命令驱动的刷新式原型，不是实时 3D；未实现键盘事件回调。
4. 曲面族为“正弦波 + 高斯丘”之和；平滑性由解析构造保证，
   测试中的平滑性/梯度检查为数值检查，不对任意用户自定义函数成立。
5. 本版本是“嵌入欧氏三维空间的光滑曲面 + 环境欧氏距离探测器”，
   不是完整的非欧几何物理仿真。
