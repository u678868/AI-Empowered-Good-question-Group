4) 世界内动态特效：飞行光球粒子与发光棱柱信标；
5) 保持 157 项测试全绿与信息安全边界不变。

二、完成的主要工作
--------------------------------------------------------------------------------
1) 视线管线（web/app.js）
   - 点击画布 requestPointerLock()；document.mousemove 在锁定态用 movementX/Y
     驱动 state.pendingYaw 与 state.pitchTarget；pitch 夹紧在 ±1.48 rad；
   - 每 90ms 把累积的 yaw 以 action=turn 同步给服务端；RenderEngine 每帧 alpha=0.18
     对 view.yaw / view.pitch 做插值；
   - 投影前把相机 forward 与 up 按 pitch 绕 right 旋转：
     forward_cam = cos(pitch)*forward_tangent + sin(pitch)*n ；
     up_cam      = -sin(pitch)*forward_tangent + cos(pitch)*n ；
   - 移动仍走 move_relative（切平面方向），因此抬头/低头不影响贴地行走。

2) 底部物品栏（web/index.html + style.css + app.js）
   - 5 槽 HUD（半透明毛玻璃，fixed 底部居中）：1 罗盘 / 2 曲率仪 / 3 测角仪 / 4 末影光标 / 5 信标；
   - 数字键 1-5、鼠标滚轮、点击槽位均可切换；槽位高亮同步；
   - 左键（锁定态）使用：slot1/2 → runTool("curvature") 等，slot4 → 生成光球并 runTool("pointer")，
     slot5 → 生成棱柱并 runTool("mark")。

3) 手持拟物模型（drawViewmodel）
   - slot1 黄铜罗盘：表盘 + 随信号升降震颤的指针 + 外圈淡蓝微光；
   - slot2 曲率仪：按 K 的符号显示上凸/下凹指示；
   - slot3 测角器：三角框 + 基线；
   - slot4 能量光球：脉冲光核；
   - slot5 测绘短杖：杖身 + 发光头；
   - 全部带 sin/cos 呼吸与行走摆动（bobbing）。

4) 世界内特效（drawWorldFX）
   - pointerParticles：使用 slot4 时在相机位置生成 3D 光球，沿 forward_3d 方向飞出，
     每帧投影绘制并随生命周期淡出后消散；
   - beacons：使用 slot5 时在脚下生成发光棱柱（自发光呼吸光效，生命周期后消散）。

5) 安全边界
   - 所有特效仅由本地已有的量化方位、俯仰与局部状态驱动；
     服务端接口未新增任何全局/出口信息，玩家状态仍不含 exit_position 与 true_distance。
