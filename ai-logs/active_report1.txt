一、任务目标
--------------------------------------------------------------------------------
在既有架构（src/the_curved_world/ 的模块职责分离 + 测试规范）基础上，实现一个
“交互式终端游玩会话”：终端输入指令 -> 游戏状态更新 -> 同一个 Matplotlib 3D
窗口实时就地重绘，不反复弹窗或关窗。

二、完成的主要工作
--------------------------------------------------------------------------------
1) 实时 3D 渲染器改造（src/the_curved_world/render.py）
   - MatplotlibRenderer 改为“就地更新”：
     * 曲面 plot_surface / plot_wireframe 只在曲面变化时创建一次并持久保留；
     * 每次刷新只移除/重建廉价动态图元：玩家 Scatter、轨迹 Line3D、
       标记点及其文本标签、历史面板 text2D。
   - 继续复用 SurfaceMeshCache（Scene.surface_key = (SurfaceConfig, nx, ny)）
     => 不再每次重绘时重建曲面网格。
   - 窗口常驻：会话开始时创建一次；刷新使用 canvas.draw_idle() + plt.pause()。
     输入 quit 时 close()；游戏胜利时 hold() 常驻展示。
   - 非 GUI 后端（Agg 等）下 pause()/hold() 静默返回，不弹警告。

2) 交互式终端主循环（src/the_curved_world/session.py，新增）
   - run_interactive_session()：阻塞式 REPL，提示符 [CurvedWorld]> 。
   - 每轮先打印紧凑状态行：(x, y, z) + 最新信号/标签/趋势 + 步数。
   - 指令集：
       move <dx> <dy>                    按方向移动固定一步（方向归一化）
       w / a / s / d                     WASD 快捷一步：w=+y s=-y a=-x d=+x
                                         （另保留 n=+y、e=+x）
       scan [note]                       原地重新获取信号与定性描述（别名 read）
       mark <name> / markers             放置 / 列出命名标记
       measure <m1> <m2>                 两个标记点间的直线欧氏距离
       curvature                         当前位置的高斯曲率 K（解析）
       log / status / help               日志 / 状态 / 帮助
       seed <n> / new [seed]             同种子重开 / 开新世界
       view player|debug                 切换渲染视图
       quit | exit                       退出会话（关闭窗口）
   - 输入流与输出可注入（input_func / echo），便于 mock 测试。
   - 健壮性：非法字符、缺参数、重名标记、未知标记等均由 CLI 捕获为清晰提示，
     不会抛异常崩溃、也不会导致窗口闪退。

3) 几何工具：解析高斯曲率（src/the_curved_world/geometry.py）
   - 新增 second_derivatives()：解析的 f_xx / f_yy / f_xy
   - 新增 gaussian_curvature()：
        K = (f_xx * f_yy - f_xy^2) / (1 + f_x^2 + f_y^2)^2
   - gameplay.ExplorationGame.curvature() 将其暴露为玩家可用的局部几何读数
     （纯几何量，不泄露任何隐藏状态）

4) 入口适配（src/main.py）
   - 新增 --play；--render 或 --play 都会拉起交互式渲染窗口。

5) 安全与信息边界审计（CRITICAL）
   - --view player 模式下，终端输出与实时渲染窗口均不显示出口坐标、
     真实欧氏距离或任何未公开的特权数据。
   - 新增测试使用“正向对照”：先确认玩家坐标确实出现在输出中，
     再断言出口坐标 / 真实距离不出现（保证断言非空转）。
   - 测试与文档中没有任何试图影响 AI 评审的语句。

七、已知限制（如实标注）
--------------------------------------------------------------------------------
1. 交互是“命令驱动 + 每次指令后重绘”，不是键盘事件驱动的实时 3D；
   未实现方向键回调。
2. 终端 input() 与 GUI 窗口并用时，输入期间窗口不响应
   （已用 plt.pause() 尽量让事件循环呼吸）。
3. 非 GUI 后端（Agg 等）不会真正显示窗口，pause()/hold() 静默返回。
4. 探测器为确定性模型、无测量噪声；移动在参数空间进行，不是测地线运动。
5. 行为变更：w 现在按 WASD 为 +y（向上），西方向请用 a；n / e 仍然保留。
