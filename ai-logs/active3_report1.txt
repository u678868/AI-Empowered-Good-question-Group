二、完成的主要工作
--------------------------------------------------------------------------------
1) 障碍物与碰撞引擎（src/the_curved_world/obstacles.py，新增）
   - Obstacle：id / u / v / position_3d / radius / kind（boulder | rift | pillar）。
   - ObstacleField：
       generate(manifold, config, seed, exclude_points, safe_margin)：
         按种子确定性散布；避开起点/出口（环境距离安全边距）；障碍物之间也保持间距；
       check_collision(u, v, player_radius)：用环境三维距离判定 —— 该度量天然处理周期接缝；
       blocking_obstacle / obstacles_near / distance_to / to_list；
   - periodic_parameter_distance()：环面参数空间最短距离辅助函数。
   - 两阶段解耦：底层曲面先生成，障碍物随后独立散布；生成器不修改曲面。

2) 世界与配置（world.py / config.py）
   - WorldConfig 新增 obstacle_count / obstacle_radius / obstacle_safe_margin（含校验）。
   - WorldState 新增 obstacles 字段（带默认值，保持既有构造兼容）。
   - WorldGenerator.generate()：先生成曲面 → 再生成障碍物 → 组成 WorldState。
   - 地图注册表 world_config_for() 支持从 placement 读取障碍物参数。
   - 尺度放大：默认环面 ring_radius 20 → 30、tube_radius 7 → 10；
     detector_scale 12 → 16、min_separation 12 → 18；障碍物 22 个 / 半径 1.6 / 安全边距 9.0。
     四张地图各自配置障碍物数量与安全边距。

3) 第一人称标架与移动（gameplay.py）
   - 新增 yaw（初始 0）与 turn(delta)（角度归一化到 [-pi, pi)）；
   - tangent_basis()：以曲面法向为 up，构造切平面正交基 (t1, t2)；
   - frame()：返回正交标架 {forward, right, up}（forward 由 yaw 在切平面内旋转得到）；
   - move_relative(direction, steps)：forward / backward / strafe_left / strafe_right，
     把目标切向量解析地展开到 (r_u, r_v) 基（用第一基本形式求解），再按参数步长推进；
   - 碰撞：move() 若新坐标被障碍物阻挡，则阻止穿透并尝试沿参数轴滑动，
     返回 MoveResult.collided=True；完全不撞时行为与之前一致。

4) 服务端 API（server.py）
   - POST /api/action/move 支持 {"action":"step","direction":...,"steps":n} 与
     {"action":"turn","angle":d}；旧的 {dx,dy} 仍兼容。
   - GET /api/state/player 新增：yaw、forward_3d / right_3d / up_3d、
     patch.X / patch.Y（三维坐标网格）、patch.vision_radius、obstacles（仅视距内）。
   - GET /api/state/debug 新增全部障碍物（供全知视角渲染）。
   - 信息边界：玩家端只返回渲染补丁范围内（vision_radius 内）的障碍物，
     绝不返回远端障碍物、出口坐标或真实距离。

5) Web 前端（web/index.html / web/app.js / web/style.css）
   - 主画布改为第一人称透视：把补丁三维网格点变换到相机标架 (right, up, forward)，
     透视投影后按深度做画家算法绘制，远处按距离淡出；视锥外的地形不绘制。
   - 障碍物以线框圆 + 十字 + 名称/距离标注（只画服务器给出的视距内障碍物）。
   - 右上角局部雷达小地图：圆形 HUD，只画以玩家为中心、固定小半径 R_radar
     的即时切片 + 障碍物红点 + 附近标记点；随 yaw 旋转（朝向朝上）。
   - 移除全局迷雾与历史足迹：不再维护探索位图、不再绘制轨迹。
   - 键盘：W/S（↑/↓）前进后退（可按住连续走）；A/D（←/→）转向；鼠标拖拽主视窗转向。
   - 上帝视角保留，并额外渲染曲面上散落的障碍物点阵与出口。

七、已知限制（如实标注）
--------------------------------------------------------------------------------
1. 第一人称前端是 Canvas 2D 手工透视投影（画家算法、无光照/遮挡剔除），
   不是 GPU 实时渲染；patch 33x33 时 /api/state/player 约 80 KB。
2. 雷达 R_radar 为补丁半径的 0.55 倍；雷达与视野都只画服务器给出的视距内障碍物，
   这是信息边界的一部分，不是渲染遗漏。
3. "移动"仍在参数空间按固定参数步长推进（不是三维等速），
   朝向只决定参数空间中的前进方向。
4. 障碍物在流形上是"点半径"体积（球体近似），不是真正的网格几何实体。
5. 既有数学限制依旧成立（椭球两极退化、曲率积分为数值积分、指向器限次量化等）。
