# The Curved World

> 一个数学探索原型：世界是嵌入普通三维欧氏空间的光滑曲面。玩家只拥有一个距离敏感探测器
> 和一张局部切空间视图，必须通过移动、测量与推理来重建隐藏的几何结构。

## 一键启动与交互说明 (Quick Start & Interaction)

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt -r requirements-dev.txt
python -m src.main --serve --port 8000
```

浏览器打开 `http://127.0.0.1:8000/`，选择地图、难度与随机种子，然后进入世界。

运行全量测试：

```powershell
.\.venv\Scripts\python.exe -m pytest -q -p no:cacheprovider
```

运行终端版本：

```powershell
.\.venv\Scripts\python.exe -m src.main
.\.venv\Scripts\python.exe -m src.main --demo-scenario
.\.venv\Scripts\python.exe -m src.main --render
```

## 三档难度模式

| 难度 | 探测器 | 指引 | 生存限制 |
| :--- | :--- | :--- | :--- |
| Easy | 有效距离信号 | 按 `H` 打开标准参考推导演示 | 绳池与标记桩限制宽松 |
| Medium | 离线 | 纯几何、曲率读数与测量 | 绳池与标记桩限制宽松 |
| Hard | 离线 | 完整生存模式 | 500 m 绳池，最多 8 个标记桩，任务倒计时随尺度变化 |

Hard 模式任务时限：

| 地图尺度 | 时限 |
| :--- | :--- |
| `0.5x` | 120 秒 |
| `1.0x` | 240 秒 |
| `2.0x` | 360 秒 |
| `4.0x` | 480 秒 |
| 自定义 `S` | `240 x S` 秒 |

倒计时归零后，本局变为 **Defeated（失败）**。失败弹窗允许玩家继续自由漫游，或返回大厅。
失败后的本局无法再获得正常通关资格。

## 五种测量工具

1. **出口探测器 (1)** - 只读取隐藏出口的信号强度。所有几何任务完成前处于封印状态；
   在 Medium 与 Hard 模式下为离线状态。
2. **标记桩 (2)** - 放置命名测量点。Hard 模式最多允许 8 个标记桩。
3. **测量绳索 (3)** - 连接两个玩家已知节点。左键选择节点，右键剪断绳索。
   Hard 模式使用有限的 500 m 绳池。
4. **测量工具 (4)** - 按 `R` 在长度与角度之间切换。长度模式可测量一条绳索或两点距离；
   角度模式可测量一个顶点夹角或三点三角形内角和。
5. **任务书 (5)** - 显示当前任务、目标、提示、进度与已收集印记。

## 通关攻略：五大几何任务

### 任务 1 - Gauss-Bonnet 角盈 / 角亏

- **几何原理**：`sum(theta_i) - pi = iint_Delta K dA`。
- **地形寻找**：角盈任务寻找正曲率凸丘；角亏任务寻找负曲率鞍槽。
- **具体操作**：放置三个标记桩，用绳索连成三角形，再使用测角器测量内角和。
- **达标判定**：角盈模式下需高于下界目标；角亏模式下需低于上界目标。

### 任务 2 - Bertrand-Diquet-Puisseux 测地圆收缩

- **几何原理**：`C(r) = 2*pi*r - (pi/3) K r^3 + O(r^4)`。
- **地形寻找**：正曲率峰顶。
- **具体操作**：在峰顶周围放置三个标记桩，连接绳索，然后在长度模式下使用测量工具
  将三角形拉成外接测地圆。
- **达标判定**：实测曲面周长比必须小于或等于自适应目标。

### 任务 3 - Levi-Civita 平行移动和乐环

- **几何原理**：绕闭合环进行平行移动后，向量旋转量等于 `iint K dA` 模 `2*pi`。
- **地形寻找**：环绕某个弯曲高地或鞍部的闭合回路。
- **具体操作**：放置起点标记，标定切向量，按顺序经过多个标记走一圈闭合回路，
  然后测量运输旋转角。
- **达标判定**：回路闭合且实测和乐角达到自适应目标角。

### 任务 4 - 抛物奇异分界线

- **几何原理**：`K = kappa_1 * kappa_2 = 0`，即至少一个主曲率为零。
- **地形寻找**：凸丘与鞍部之间的过渡边界。
- **具体操作**：在零曲率分界线上放置三个彼此分离的标记桩，连接绳索，然后执行
  抛物分界线验证。
- **达标判定**：三个标记桩均位于容差带内，并且间距有效。

### 任务 5 - 同伦大圆周游

- **几何原理**：`pi_1(T^2) = Z + Z`；非零缠绕类无法收缩为一个点。
- **地形寻找**：闭合环面或把手结构。
- **具体操作**：放置原点信标 `O`，沿一个完整坐标周期移动，回到 `O`，然后封印同伦环。
- **达标判定**：展开后的缠绕数非零，并且路径返回时位于捕获半径内。

## 知识如何成为游戏规则 (How the Knowledge Becomes the Game Rules)

五个定理不是装饰：每一条都是解封出口探测器的**唯一**途径。

| 定理 | 游戏规则 | 玩家端后果 |
| :--- | :--- | :--- |
| Gauss-Bonnet，`sum(theta_i) - pi = iint K dA` | 用测角仪测量测地三角的内角和，并与同一三角的曲率积分比较。 | 角盈与角亏两类任务要求的曲率符号相反，同一工具必须以相反意图使用两次。 |
| Bertrand-Diquet-Puisseux，`C(r) = 2*pi*r - (pi/3) K r^3 + O(r^4)` | 用绳索把三角拉成外接圆来**构造**测地圆，再把曲面周长与欧氏周长比较。 | 玩家亲自完成展开式，而不是阅读它：圆是绳索几何，不是一个菜单项。 |
| Levi-Civita 和乐 | 沿标记点构成的闭合回路执行平行移动，并测量净旋转角。 | 测得的旋转等于所围曲率积分，回路走错会被量具本身暴露。 |
| 抛物点，`K = kappa_1 * kappa_2 = 0` | 三根桩必须落在零曲率容差带内且间距合法。 | 玩家要找的是穹顶与鞍座之间的分界线，即一条曲线而非一个点。 |
| 同伦，`pi_1(T^2) = Z + Z` | 必须走完一整圈坐标并封环，展开后的绕数不能为零。 | 可收缩的小回路无法封环，玩家必须推理地图的拓扑。 |

### 曲面模型

世界是一张嵌入普通欧氏空间的图曲面：

```text
S = { (x, y, f(x, y)) : (x, y) in D }
```

`D` 是参数域，`f` 是由正弦波与高斯丘叠加而成的光滑高度函数。所有一阶与二阶导数
均为解析求导；项目的核心几何计算不使用有限差分导数。

探测器使用环境欧氏距离：

```text
d_E(P, Q) = ||P - Q||_2
signal = exp(-d_E / scale)
```

这不是曲面上的测地线距离。探测器只报告信号强度，绝不会暴露隐藏出口、真实距离或方向。

## 信息边界

面向玩家的 API 响应绝不包含隐藏出口坐标或真实出口距离。特权上帝视角与
`/api/state/debug` 端点仅在服务器以 `--debug` 启动，或会话以全知模式建立时可用。

## 计分与学者段位

最终得分由四个部分组成：

- **通关基础分**：到达出口时 `+2000`。
- **时间效率分**：最高 `+3000`，按实际用时相对 `240 x scale` 计算。
- **节约测量分**：由标记桩克制、剩余绳长比例与测量调用纪律组成。
- **路径消耗惩罚**：扣除 `min(1000, effective_steps x 0.2)`。

小计会乘以难度倍率（Easy `1.0`、Medium `1.5`、Hard `2.2`）与地图尺度倍率
（`0.5x -> 0.8`、`1x -> 1.0`、`2x -> 1.25`、`4x -> 1.5`，
自定义为 `clamp(0.8 x sqrt(S), 0.6, 2.0)`）。最终分数下限为 `100`。

学者段位：

| 分数 | 段位 |
| :--- | :--- |
| `>= 8000` | `S` - Archimedean Grandmaster |
| `>= 5500` | `A` - Geodesic Scholar |

| 作品 | 简介 | 本作的不同 |

本作独有的组合：

1. **无缝二维局部切空间视图**：玩家固定在中心、世界滚动，跨周期接缝用相对图卡增量处理，
   接缝处不会撕裂，也不需要三维相机视锥。
2. **知识是唯一的钥匙**：五个几何印记全部集齐前出口探测器封存，玩家载荷永远不含出口坐标与真实距离。
3. **测量即构造**：三根桩加一条被拉成外接圆的绳子，本身就是 Bertrand-Diquet-Puisseux 测地圆。
4. **实时推导演播台**：每个印记都会打开双栏 KaTeX 推导，逐步重演本局真实数值，而非静态说明卡。

## 核心设计决策与技术取舍 (Core Design Decisions & Trade-offs)

1. **用二维局部切空间视图取代三维第一人称相机**：嵌入曲面没有"天然前方"，早期三维第一人称
   原型在障碍物与接缝附近出现穿模与不平滑。局部切空间视图消除了这类问题，用网格畸变让度量
   可见，仪表读数也一目了然。代价：沉浸感下降，没有地平线，曲面靠推断而非直视。
2. **探测器使用环境欧氏距离而非测地距离**：变曲率曲面上的测地距离需要逐次求解 eikonal 方程，
   且会泄露度量本身。环境距离解析、确定，并迫使玩家使用内蕴测量。代价：探测器不是内蕴量，
   因此游戏提供内蕴工具（测角仪、平行移动、绳长）作为补偿。
3. **自适应且宽容的任务阈值**：解析目标精确，但玩家放置桩是像素级操作。阈值随局部曲率量级
   缩放，使 `0.5x`-`4x` 各尺度下所需的物理精度大致一致。代价：高曲率地图比平坦地图更宽容。
4. **Hard 模式有限绳池**：绳子成为预算资源，增加规划层次并计入"节约分"。代价：惩罚自由探索，
   因此只在 Hard 模式启用。
5. **客户端负责移动、服务端负责真相**：浏览器以 60 FPS 本地积分获得零延迟手感，约每 200 ms
   回报一次位置；服务端仍掌握世界状态、碰撞审计、胜利判定、计时与全部特权数值，并对采纳的
   位置重新钳制。代价：容忍客户端/服务端之间的微小偏差。
6. **仅用标准库的 HTTP 服务**：无框架、无构建、无部署风险，`python -m src.main --serve` 就是全部。
   代价：没有服务端推送，客户端以 200 ms 轮询代替事件推送。
7. **Hard 采用"按任务"倒计时**：每个印记都是独立的限时训练，单任务内倒计时单调递减，只有
   接受新任务才会重置。代价：若改为整局单一倒计时，第五个任务几乎不可能完成。
8. **计分向"节约"倾斜**：只算时间会奖励莽撞冲刺，因此标记、绳长与量具使用纪律同样计分。

## 数据说明 (Data Statement)

- **全部为程序化数据**：流形参数、地形起伏、障碍物布置、起点与隐藏出口都由数学模型按显式
  种子生成，没有导入任何地形/网格/高度图资源。
- **无真实世界与个人数据**：项目不含人脸、位置信息、用户账号、遥测，也不含师生评价内容；
  服务端仅绑定 `127.0.0.1`，不向任何服务器上传数据。
- **无第三方数据集与素材**：所有图像来自本项目自身的几何内核（Matplotlib 渲染）或运行中的
  网页界面截图。
- **可复现性**：固定种子 `12345` 可复现同一曲面、起点、出口与全部推导数值；演播台是实时计算，
  不是回放录屏。
- **合成随机**：涉及随机的部分（障碍物散布）来自带种子的确定性生成器，同种子必得同世界。

## 已知限制

- 渲染器是轻量本地 canvas / Matplotlib 原型，并非完整游戏引擎。
- 探测器为确定性模型，目前没有测量噪声。
- 移动发生在参数空间中，不是测地线物理仿真。
- Klein 瓶、实射影平面与打结环面均为浸入模型，因此环境空间中的自交是刻意的数学性质，
  不是渲染缺陷。
- `double_torus` 是亏格 2 的视觉近似；其参数域仍然是亏格 1。
- Hard 模式刻意严苛：同时组合 500 m 绳池、8 个标记桩与任务倒计时。
- 眼指针（限定 3 次、给出量化切平面方位）已在服务端内核实现，HUD 也显示剩余次数，但当前
  网页版没有为它提供按钮或快捷键：`1`-`5` 热栏是 探测器 / 标记桩 / 绳索 / 量具 / 任务书。
  大厅里仍写着 "eye pointer" 的文案属于历史遗留措辞。
